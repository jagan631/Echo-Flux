# 🌍 EcoFlux Intelligence

> AI-powered sustainability platform that analyzes data center infrastructure and provides intelligent recommendations to optimize energy consumption, carbon emissions, water usage, and operational efficiency.

---

## 📖 About the Project

EcoFlux Intelligence was developed during the **AM Jain College Hackathon** by our team to address sustainability challenges in modern AI infrastructure and data centers.

The platform analyzes environmental and operational metrics to generate insights that help organizations reduce their carbon footprint while improving efficiency.

This repository is intended for contributors and new team members who want to understand the project architecture and continue its development.

> **Project Type:** Hackathon Team Project

> **Development Style:** This project was **AI-assisted (Vibe Coded)**. AI tools accelerated development while the team focused on architecture, implementation, debugging, validation, and feature integration.

# ⚙️ Getting Started

## Clone Repository

```bash
git clone <repository-url>
```

## Install Frontend

```bash
cd ecoflux_frontend
npm install
```

## Install Backend

```bash
cd ecoflux_backend
pip install -r requirements.txt
```

## Configure Environment Variables

Create `.env` files for both frontend and backend.

## Run Backend

```bash
python main.py
```

## Run Frontend

```bash
npm run dev
```
